# HR-Genius: Conversational Automation with AI of HR Processes

## Description
AI-powered HR automation platform for document generation, workflow management, and HR assistance.

## Tech Stack
- Frontend: React + TailwindCSS
- Backend: Node.js (NestJS/Express)
- Database: PostgreSQL + Prisma
- AI: Gemini + LangChain
- Automation: n8n

## Branches
- main → stable release
- dev → active development
- feat/backend → backend features
- feat/frontend → frontend features
